Solar System Navigator

3D N-body solar system sim · SI physics · KSP-style map & maneuvers

Play in browser

WebGPU build (Chrome/Edge recommended). Same N-body sim; loads ~40 MB with 2k textures.

Launch WASM

Host the Trunk dist/ output at /play/ on your site, or use Cloudflare Pages — see docs/DEPLOY.md.

Download (Linux)

Native desktop app — Vulkan/OpenGL, ~1280×720.

Linux x86_64 (.tar.gz)

After download: extract, then run ./solar-system-navigator from the folder. First run may download planet textures.

Build from source

  • Rust 1.95+, Bevy 0.18
  • git clone https://github.com/djmango/solar-system-navigator.git
  • cargo run --release

Controls (quick)

  • Click planets to select · Space to pause/run
  • M — map mode · V — N-body orbit paths
  • LMB orbit camera · Scroll zoom
